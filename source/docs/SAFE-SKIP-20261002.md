# A-button skip safety status

V31 DialogueSkipV30.h selects only the current/unambiguous same-level scene,
identifies TALK/SAY lines, invokes original CutSkip and restores non-speech timers.
It leaves movement and cue waits intact. HP1 source was read only.

HP2 uses CutScene.aThreads with CutScript pending cues rather than HP1 Cast[].
Its FastForward path includes broader script advancement. Retail Engine.u confirms
Pawn.DoingTalk with CutCue and AnimEnd, and Pawn.CutCommand_Talk. The exact speech
completion cue semantics have not been validated yet; HP1 timer offsets and voice
slot assumptions must not be copied.

A remains bound to skip_dialog on Touch but no longer sends generic Enter.
Until speech-only HP2 completion is verified it logs one deferred request per
press and leaves all game state unchanged. This is a safety gate, NOT completed
cutscene skipping. Do not advertise A as functional skipping in this build.

Next: inspect retail DoingTalk/CutCommand_Talk bytecode and ownership of its timed
cue; implement only an unambiguous same-level current-speech completion, preserving
native notification and movement waits. Test repeated/held A, parallel scenes,
reward delivery, map travel and save/reload before enabling it.
