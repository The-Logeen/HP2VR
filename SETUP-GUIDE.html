HP2VR: from downloads to your first VR game

This guide opens offline; download links require internet. The installer does not download dependencies automatically. Keep your original game and existing working VR installation.

No dgVoodoo installation is required. HP2VR uses the HP2 DX11 renderer. You need complete supported game files, but do not need to repair their original flat-screen graphics configuration first. This is Windows PC VR, not a standalone Quest APK.

1. Get the mod and base game

  1. Open the HP2VR releases page. Choose the newest release, expand Assets, and download HP2VR-v…zip, not the automatically generated “Source code” archives.
  2. In File Explorer, right-click the ZIP, choose Extract All, and extract it into a writable folder such as Documents. Do not run setup inside an archive.
  3. Open the extracted folder until you see Install-HP2VR.cmd, Setup-HP2VR.ps1, installer, and payload. Keep them together.
  4. Install or fully extract your own Windows PC copy of Harry Potter and the Chamber of Secrets. If the download contains a setup program, extract the download first and run that program. Select the installed game, not its setup EXE or disc image.
Game folder ← select this in HP2 game folder
  System\Game.exe
  System\Core.dll
  Maps\
  Textures\
  Sounds\

The tested MagiPack copy matches our supported build. Other distributions are accepted when the required game identities match. A distribution name alone is not proof. A different executable or engine needs compatibility investigation; do not replace arbitrary DLLs to bypass checks.

2. Get HP2 DirectX11 Renderer 1.6.2

  1. Open the version-specific renderer download page and download the archive. Author's project.
  2. Extract the entire archive, including shaders. Find the folder containing both Common and Harry Potter 2.
  3. In setup's Renderer folder, select that parent folder. You do not need to copy files into your original game.
Renderer folder ← preferred selection
  Common\D3D11Drv.int
  Common\Effects11.dll
  Common\d3d11drv\...shader files...
  Harry Potter 2\d3d11drv.dll

If already installed, select the game root containing System, or leave Renderer blank to use the selected game folder. This updated installer also recognizes selection of System, Common, or Harry Potter 2 when the matching files are adjacent. Every resolved component is still verified. It does not combine arbitrary downloads elsewhere on your PC.

3. Get OpenVR 2.15.6

  1. Open Valve's OpenVR 2.15.6 release.
  2. Expand Assets and download Source code (zip). Unlike the mod's source archive, this SDK archive includes the prebuilt DLL we need.
  3. Extract it. Locate bin\win64\openvr_api.dll.
  4. Select the extracted SDK root in OpenVR SDK folder or DLL. Alternatively paste the full DLL path.
openvr-2.15.6 ← preferred folder selection
  bin\win64\openvr_api.dll ← correct for our 64-bit companion
  bin\win32\openvr_api.dll ← NOT the required DLL

The updated installer also accepts bin or win64 as the selected folder, and removes surrounding quotes from pasted paths. A win32 or unverified DLL is not accepted just because it has the same name. OpenVR is not OpenAI, and it does not replace SteamVR.

4. Install Microsoft's prerequisites

Visual C++ 2010 x86

  1. Open Microsoft's VC++ 2010 SP1 MFC Security Update.
  2. Click Download and select vcredist_x86.exe.
  3. Run it and finish setup. Restart if requested. Use x86 even on 64-bit Windows because the renderer is 32-bit.

Legacy DirectX libraries

  1. Open Microsoft's DirectX June 2010 runtime download.
  2. Download and run directx_Jun2010_redist.exe. Choose a temporary extraction folder.
  3. Open that folder and run DXSETUP.exe. Extraction alone is not installation.

These legacy libraries coexist with modern Windows DirectX. Do not download individual DLLs from DLL-download sites. The HP2VR installer does not run these Microsoft installers for you. File-presence checks are not full runtime health tests.

5. Optional HD textures

  1. Open Akven's HP2 ESRGAN 4x pack.
  2. Download HP2_ESRGAN_Textures.7z, then extract it with an archive tool supporting 7z.
  3. Select its Textures folder in the optional texture field. DDS files may be inside subfolders.

Leave blank for base textures on a fresh installation. Do not delete original UTX packages. Updates retain existing DDS textures. No ReShade or extra wrapper is required.

6. Prepare SteamVR

  1. Install Steam and sign in.
  2. Install SteamVR.
  3. Set up your headset manufacturer's PC connection software or your existing PC-VR connection.
  4. Connect the headset and controllers, start SteamVR, and confirm tracking works before testing HP2VR.

A Quest needs a PC-VR connection; copying these Windows files onto the headset will not work. SteamVR in a non-default Steam library may require manual verification even if setup says Check manually.

7. Run guided setup

  1. Close HP2 and HP2VR. Double-click Install-HP2VR.cmd in the extracted mod package.
  2. HP2 game folder: Browse to the root containing System and Maps.
  3. Renderer folder: select the extracted Common/HP2 parent described above. Blank means use the game folder.
  4. OpenVR: select the SDK root or paste the full win64 DLL path.
  5. HD textures: select extracted Textures or leave blank.
  6. Update from: leave blank for fresh setup. To migrate an existing complete HP2VR installation, select its root instead; setup then takes game, renderer and OpenVR from that old installation.
  7. New installation folder: choose a parent using Browse, then enter a new unused folder name such as HP2VR-Play. Do not create that final folder first. Keep it outside the package and old installation.
  8. Click 1. Check requirements. Double-click a component row for full details and corrective steps.
  9. Resolve missing or wrong-version items. Install missing Microsoft runtimes before playing, even if setup allows copying.
  10. Click 2. Install / update. Wait for explicit success, then click Open installed folder.

The installer creates an isolated game copy, installs the verified renderer and mod, and writes private configuration. It does not need dgVoodoo or a successful launch of the source game's original graphics setup. It does not overwrite your original game or automatically import unrelated flat-screen saves.

8. First launch and every later session

  1. Open the new installed folder and read FIRST-RUN.html.
  2. Connect the headset, start SteamVR, and confirm both controllers are tracked.
  3. Double-click Start-HP2VR.cmd. Do not use the original game's shortcut or launch Game.exe directly for VR.
  4. In the headset, confirm the full stationary menu is visible. Use the right-hand pointer and trigger to select New Game or Load Game.
  5. Confirm gameplay appears, head tracking works, movement responds, and the wand works. These are headset acceptance checks, not things the installer's file checks can prove.
  6. For later sessions, use the same launcher. Do not reinstall each time. Saves in separate installations do not synchronize.

9. Missing, close, incompatible, or blocked?

A nearby folder is fine when its files verify. Setup resolves common nearby layouts and shows the resolved renderer/OpenVR path after a successful check. Different binary versions remain unverified unless explicitly supported. A similar name is not a compatibility test.

  • Renderer Missing: read the searched path. Extract the full 1.6.2 archive and select the parent of Common and Harry Potter 2. One DLL without shaders is incomplete.
  • OpenVR Missing: find bin/win64/openvr_api.dll inside the extracted 2.15.6 SDK and select its root or paste the exact file path. If your extraction has an extra nested folder, open it first.
  • Wrong version: the file exists but does not match the supported identity. Use the named release; do not rename files or bypass checks. Provide diagnostics to investigate another build.
  • Game Missing: select the installed game root, not its archive or System folder.
  • Destination Exists: use another new destination. Existing saves/installations are not overwritten.
  • Blocked or installer failure: click Open diagnostic logs. Keep any INSTALL-INCOMPLETE folder. Share the component, full Details, and logs; review paths/usernames before posting. Do not disable antivirus or add broad exclusions.
  • Only desktop output or SteamVR room: verify your PC-VR connection, use the installed VR launcher, and report the companion/game logs. A successful installation is not proof that headset submission succeeded.

Fresh saves from another flat-screen copy are not automatically migrated. Supported Update from creates a new sibling installation with the old installed copy's saves/settings; the old copy stays available.
