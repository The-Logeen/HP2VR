Start SteamVR and connect your headset, then double-click Start-HP2VR.cmd.
The game starts at its normal menu. Start a new game; existing saves are not imported.
Saves: runtime\Home\Harry Potter II\Save
Settings: runtime\System\HP2VRSettings.ini
Right grip + Y opens VR settings; Y opens the game menu.
Frame: left View opens game menu; right grip + left View opens VR settings.
Read FRAME-CONTROLS.md for bindings, independent aim angles and troubleshooting.
This is an experimental PCVR mod, not a native Quest application.
VC++ 2010 x86 and legacy DirectX download links are in the original
package's DOWNLOADS-AND-INSTALL.md. Install only if needed. SteamVR and headset
connection software must be installed separately.
Uninstall: close HP2VR, back up saves/settings, then delete THIS isolated
installation folder only. Your original game is not modified by this installer.
