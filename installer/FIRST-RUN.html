Welcome to HP2VR

This is a Windows PC VR mod, not a standalone Quest APK. Connect your headset to the PC and confirm it works in SteamVR.

  1. Install any missing Microsoft prerequisites listed by setup. Close other HP2/HP2VR sessions.
  2. Start SteamVR and connect both controllers. Open Start-HP2VR.cmd in the installed folder.
  3. The game should start at its normal menu on a stationary VR panel. Point with the right controller and use the trigger to select New Game or Load Game.
  4. Stand naturally when gameplay first gives you control, for automatic body-height calibration.
  5. Use Y for the game menu. Right grip + Y opens VR settings, including eye height, world scale and rotation options. Use SteamVR's reset/recenter to reset your forward direction.

Next time

Connect the headset, start SteamVR, and run the same Start-HP2VR.cmd. No reinstall or dependency downloads are needed. Load your saved game from the menu.

Saves and updates

Saves live under runtime\Home\Harry Potter II\Save (and the legacy runtime\Save folder). VR preferences are in runtime\System\HP2VRSettings.ini. Keep the whole installed folder together.

To update, select the old installed folder in setup's Update from field and choose a new destination. Saves, input preferences, VR settings and existing HD textures are copied. Renderer/game defaults are refreshed. The old installation stays untouched; use the NEW folder's launcher afterward. Saves created after updating are not synchronized back to the old copy.

If something fails

Do not disable antivirus or add broad exclusions. Report the exact error and blocked filename. An INSTALL-INCOMPLETE marker means setup did not finish; do not launch that copy. Setup diagnostic logs are in the Windows temporary folder, named HP2VR-Setup-*. Game logs are under runtime\Home\Harry Potter II; companion logs are under runtime\VR.
